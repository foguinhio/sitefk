# Confissões do Foguinho

Site estático em HTML, CSS e JavaScript, publicado pelo GitHub Pages.

## Visualizar o site

Abra `index.html` no navegador. Para testar localmente, abra a pasta no VS Code e use uma extensão de servidor estático, como Live Server.

## Atualizar o conteúdo

Edite `content.js`: `book.purchaseUrl` configura a compra; `author` contém nome e Instagram; `texts` contém publicações; `quotes` contém citações. As imagens usadas pelo site ficam em `assets/`.

## Publicar

Em **Settings → Pages**, selecione **Deploy from a branch**, a branch `main` e `/(root)`. Endereço esperado: https://foguinhio.github.io/sitefk/ .

Sem backend configurado, comentários ficam apenas neste navegador e o chatbot permanece desativado. Não coloque chaves de API no JavaScript público.
